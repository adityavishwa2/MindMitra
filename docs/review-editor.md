# Review and publish CBT questions

Open **Administration → Review papers → Review paper**. Compare the original uploaded PDF with the editable question text and options. The administrator can use full-page previews and the optional original-question image; students receive the checked CBT text/options after publication.

1. Check the exam/year, scoring and source reuse permission.
2. Read each question and its options, correcting uncertain OCR. Choose the correct MCQ option or all correct MSQ options. **No answer-key reference field is required.**
3. Use **Save answer & next** to store private progress. Use **Read text from PDF** if a scan needs another OCR attempt. Missing questions/options can be added; detailed metadata and option removal are under Question settings.
4. **Finish review and publish to practice** publishes the checked paper directly to examination PYQ. Placeholder scan text/options cannot be published. Missing/disputed answers can still be handled through Other decisions and remain unscored.

Student progress is recorded through student practice attempts, not reviewer selections. Historical attempts keep their snapshots. Only administrators can review/publish, and source authorization remains part of approval.

See [CBT and Shorts](cbt-and-shorts.md) for limits, original-paper comparison, older image-backed attempts and Windows update commands. Advanced JSON is optional for bulk work; no separate JSON import is required after a PDF is approved.
