# Progress, games, and videos

## Practice and progress calculations

Full timed papers use the source paper’s duration, marks, and penalty. Untimed sessions can filter a single paper by subject, topic, previous incorrect attempts, bookmarks, unsolved questions, and question limit. This version does not combine multiple papers in one session. Quiz text and answer keys are snapshotted at launch; original language is preserved.

A verified key awards `paper.marks` for a correct selected option and subtracts `paper.penalty` for an incorrect selection. Skips receive zero; disputed, unavailable, and descriptive keys are unscored. Accuracy divides correct by correct-plus-incorrect scorable answers, not all displayed questions. No scorable attempts means an em dash, not invented zero accuracy. Results are immutable and repeated submission is idempotent.

Analytics count submitted sessions. Total attempts can grow on retries; unique counts use a set of actually answered question IDs. A full paper is complete only if its nonempty current verified question set is covered by the user’s submitted answers. All published shifts contribute to year denominators, so one completed shift cannot complete another. Historical collection completeness is never inferred from personal progress. Current/longest streaks use actual submitted activity dates in Asia/Kolkata.

Focused-time recording uses bounded server heartbeats while the practice page is visible, independently of the simulation deadline. Leaving for a game stops heartbeats. It is an activity estimate, not attention measurement. The first/last short heartbeat interval may be omitted. Game and watch time never increases exam scores. A timed simulation uses wall-clock time and does not offer an interrupting study-break prompt.

A break link carries only a validated local `/practice/<id>` return destination. Answers sync in the background and unsynced selections remain device-local by session ID until reconnection. An active timed session rejects late answer changes; reconnecting after its deadline cannot recover permission to submit new answers. Offline exam content is not cached.

The progress screen offers browser print/save-to-PDF and CSV progress export, plus a JSON account export in Settings. Exam/date report filters, long-term comparison insights, and notification scheduling are not implemented yet.

## Four complete initial game loops

- Memory Match: shuffled pairs, three board sizes, mismatch reset, move counter, completion, restart, device resume, private result saving.
- Number Merge: one-merge-per-tile rules, directional keyboard/buttons/swipes, tile generation, score, undo, no-moves detection, restart, device resume.
- Pattern Pulse: timed playback, growing randomized sequence, input validation, score, finish/restart. Pause is disabled during playback. No saved mid-sequence replay is claimed.
- Sliding Puzzle: solvable 3×3 boards generated by legal moves, legal-move validation, move counter, win detection, restart, device resume.

Scores are personal and self-reported, never competitive or official exam results. No medical/IQ claims. Pause, keyboard/touch controls, reduced-motion CSS, and a five-minute gentle reminder are shared. Games run without login; authenticated users can save completed results. Sound, Sudoku, Word Connect, Maze Escape, Color Calm, Logic Lab, Spot the Difference, more sliding sizes, and achievement expansion remain incremental work.

Add a game to `lib/game-catalog.ts`, implement rules in a pure module with tests, add its client renderer, and add its slug to the server game-session schema. Lazy route loading keeps games off study pages. Zustand/TanStack Query packages are available; current small interactions use local React state and server-rendered data instead of unnecessary stores.

## Learn Shorts

Only approved eleven-character YouTube IDs are embedded from `youtube-nocookie.com`, after an explicit Play action. Attribution and source links remain visible. Native player controls provide captions, mute, play/pause, and fullscreen. The feed is capped at twenty approved items, supports topic filtering, bookmarks, reporting, and previous/next/swipe navigation. Five- or ten-minute visible-player sessions end with a return-to-study action.

Time measures visible player-open duration, including native player pauses; it is not verified playback time. It is periodically saved in bounded chunks. Exact provider event tracking, daily cross-device limits, saved-video feeds, metadata refresh workers, and embed takedown checks are future work. No videos were fabricated or pre-approved merely to fill this section.
