# Mind Break update

Video navigation and admin video queues have been removed. Legacy video pages redirect to games; upload, media, review and like endpoints return 410. Database records and files are preserved. No destructive migration is included. The cloud image no longer installs FFmpeg; PDF OCR still uses Poppler and Tesseract.

Three new browser games join the four existing games:

- Paper Ball Toss: swipe/drag or aim/power sliders, changing wind, five-throw rounds and unlimited practice.
- Bridge Builder: grid construction, wood/steel, budget, undo/redo, two vehicle loads and star ratings. A small linear elastic truss solver checks stability, axial forces and displacement at five load positions. It is a simplified game model, not an engineering design tool. Crossed beams only connect at endpoints.
- Paper Football: compact eight-direction grid variant, no repeated edges, visited-point/wall bounces, own goals and trapped-player losses. Easy bot chooses random legal moves; normal bot prioritizes goals, blocks immediate opponent wins and advances toward its goal.

Each new game includes three swipeable rule cards, a practice round, pause/restart and a five-minute return-to-study reminder. Pointer gestures and keyboard-accessible controls work without additional browser permissions. New game progress lasts for the current visit; no competitive leaderboard or persistent score upload is claimed. Existing classic games keep their existing score functionality.

Carrom, Gomoku and seed games are not part of this first release. No domain, hosting plan or paid service has been purchased by this update.
